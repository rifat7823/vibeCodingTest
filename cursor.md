# cursor

This project is a Node.js project. It is TypeScript based, and the app is built with Next.js.

- Runtime: Node.js
- Language: TypeScript
- Framework: Next.js (App Router, React)
- Styling: Tailwind CSS
- Source: `src/app`
- Package name: `a-vibe-coding`

Run the app with `npm run dev`. The dev server is at http://localhost:3000.
